# Node-Barber

Sistema de gerenciamento desenvolvido para ajudar cabeleireiros e barbearias a administrar seus negócios de forma simples e organizada.

## 🎯 Objetivo

O **Node-Barber** tem como objetivo centralizar a gestão de uma loja, facilitando o controle de:

* 👥 **Clientes** — cadastro e gerenciamento de clientes
* 💰 **Finanças** — acompanhamento de receitas, despesas e movimentações financeiras
* 🏪 **Loja** — gerenciamento das informações e operações do estabelecimento

A proposta é transformar tarefas administrativas que normalmente são feitas de forma manual em um sistema organizado e fácil de utilizar.

## 🚀 Instalação

Clone o repositório:

git clone https://github.com/RaphaelMonteiroP/Node-Barber.git


Entre na pasta:

cd Node-Barber


Instale as dependências:

npm install

## ▶️ Desenvolvimento

Para iniciar o projeto em modo de desenvolvimento:

npm run dev
